# 🎓 HỆ THỐNG MƯỢN – TRẢ THIẾT BỊ GIẢNG DẠY  
## Trường Đại học Trà Vinh

## 📌 Giới thiệu
Hệ thống mượn – trả thiết bị giảng dạy là một website hỗ trợ công tác **quản lý, đăng ký, mượn, trả và theo dõi tình trạng các thiết bị giảng dạy** tại Trường Đại học Trà Vinh.  
Hệ thống được xây dựng nhằm số hóa quy trình quản lý thiết bị, giảm thao tác thủ công, nâng cao hiệu quả vận hành và minh bạch dữ liệu.

Website phục vụ cho nhiều đối tượng sử dụng như **giảng viên, sinh viên, cán bộ quản lý và quản trị hệ thống**, đảm bảo phân quyền rõ ràng và an toàn dữ liệu.

---

## 🎯 Mục tiêu hệ thống
- Quản lý tập trung toàn bộ thiết bị giảng dạy
- Hỗ trợ giảng viên đăng ký mượn thiết bị nhanh chóng
- Kiểm soát quy trình mượn – trả – bảo trì – xử phạt
- Cung cấp báo cáo, thống kê phục vụ công tác quản lý
- Nâng cao tính minh bạch, chính xác và hiệu quả vận hành

---

## 👥 Đối tượng sử dụng
- **Giảng viên, sinh viên**: đăng ký mượn, trả thiết bị
- **Cán bộ quản lý thiết bị**: duyệt yêu cầu, quản lý kho, báo bảo trì
- **Quản trị viên hệ thống**: quản lý người dùng, danh mục, báo cáo, bảo trì, Log Audit

---

## ⚙️ Chức năng chính

### 🔐 Xác thực & phân quyền
- Đăng nhập hệ thống
- Phân quyền theo vai trò (Giảng viên/ Sinh viên / Cán bộ / Admin)
- Quản lý tài khoản người dùng

### 📦 Quản lý thiết bị
- Thêm, sửa, xóa thiết bị
- Phân loại thiết bị theo nhóm, phòng ban, khoa
- Theo dõi tình trạng: sẵn sàng, đang mượn, hư hỏng, bảo trì

### 📋 Mượn – trả thiết bị
- Giảng viên, sinh viên gửi yêu cầu mượn thiết bị
- Cán bộ duyệt / từ chối yêu cầu
- Ghi nhận thông tin trả thiết bị
- Xử lý trả trễ và vi phạm (nếu có)

### 🛠️ Bảo trì & xử phạt
- Ghi nhận lịch sử bảo trì thiết bị
- Quản lý mức phạt khi trả trễ hoặc làm hỏng thiết bị

### 📊 Báo cáo & thống kê
- Thống kê số lượt mượn, trả, đặt trước
- Thống kê số lần phạt, bảo trì thiết bị
- Xuất báo cáo phục vụ công tác kiểm tra, đánh giá

### 📝 Nhật ký hệ thống (Audit Log)
- Ghi nhận các thao tác quan trọng trong hệ thống
- Hỗ trợ truy vết và kiểm soát hoạt động người dùng

---

## 🛠️ Công nghệ sử dụng
- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP thuần
- **Cơ sở dữ liệu**: MySQL
- **Công cụ hỗ trợ**:  
  - Git & GitHub  
  - Postman
    
---

## 🚀 Hướng dẫn cài đặt (tóm tắt)
1. Clone source code từ GitHub
2. Cấu hình cơ sở dữ liệu
3. Import file SQL trong thư mục `database`
4. Cấu hình biến môi trường
5. Chạy backend và frontend
6. Truy cập website qua trình duyệt
